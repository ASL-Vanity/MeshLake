# MeshLake 已验证成员目录与单播路由

## 目标

早期原型把虚拟网络数据作为网络级广播发送：直连时复制给所有已发现成员，中继时使用空目标设备 ID。该方式便于验证加密链路，但设备数量增加后会浪费带宽，也无法为入站源地址建立明确的成员归属。

当前数据面已经改为基于控制器签名成员证书的真实单播：

```text
虚拟目标 IP
    │
    └──> 已验证成员目录 ──> 目标 DeviceId
                              ├──> 最佳直连候选
                              └──> 指定 DeviceId 的中继转发
```

## 地址目录来源

虚拟地址不能由普通客户端自行声明，只能来自成员证书中的 `assigned_addresses`：

- 根节点验证设备签名、设备公钥和控制器签名后，在签名根响应中返回成员地址与候选端点。
- 中继注册使用设备私钥签名的注册消息，证明发送端持有证书绑定的设备私钥。
- 每次根节点和中继注册都包含随机 nonce；服务端在 5 分钟窗口内拒绝重复 nonce，防止攻击者重放已签名注册包来劫持设备的观察端点。
- 中继成员目录帧携带完整成员证书；接收客户端使用本网络已钉扎的控制器公钥再次验证证书。
- 地址必须位于本机已经加入的对应 IPv4/IPv6 网络前缀中。
- 与本机或同一网络其他成员重复的地址目录会被拒绝。

根节点和中继分别在 90 秒无刷新后删除成员；客户端的虚拟地址目录在 120 秒无刷新后失效，避免旧成员缓存阻止地址重新分配。

## 出站选择

- 普通 IPv4/IPv6 单播只选择拥有目标虚拟地址的一个设备。
- 目标未知时直接丢弃，不会降级成全网广播。
- IPv4 有限广播、网络广播、组播以及 IPv6 组播会展开为逐成员目标列表。
- 即使是广播或组播，每个外层加密帧仍填写具体目标设备 ID，因此中继不会把同一密文再次广播给所有成员。
- `Preferred` 优先直连、失败后中继；`Required` 始终中继；`Disabled` 只允许直连。

## 入站检查

解密后的数据包进入 Wintun/TUN 前必须满足：

1. 外层目标设备是本机；只有合法广播/组播兼容帧可以使用空目标。
2. IP 源地址属于外层源设备的已验证成员目录。
3. 普通单播目标地址属于本机；广播或组播目标必须符合对应网络规则。

## 协议兼容性

- 根响应新增的 `assigned_addresses` 使用 Serde 默认值，旧根响应仍可解析，但没有地址目录时不会用于新单播数据面。
- 新根响应同时携带完整成员证书；没有证书的旧目录项不会用于建立成对会话。
- 中继新增 `RELAY_PEER_IDENTITY` 成员证书帧。
- 中继注册升级为 `RELAY_REGISTER_SIGNED`，旧的无设备签名注册不再接受。客户端与中继应一起升级。
- 新数据面使用 `RELAY_SESSION_INIT`、`RELAY_SESSION_RESPONSE` 和 `RELAY_SESSION_DATA`。新客户端拒绝旧的网络共享密钥数据帧，根节点、中继和客户端应一起升级。

## 当前安全边界

每个网络仍有一把成员共享的网络 PSK，但它只参与 HKDF 会话派生。每一对设备还必须完成由各自 Ed25519 身份认证的一次性 X25519 握手，数据包使用成对临时密钥，因此单个普通成员不能仅凭网络 PSK 构造声称来自其他设备的有效数据帧。

当前仍未实现在线证书吊销和平台安全密钥库。已获得合法成员证书、设备私钥及网络 PSK 的失陷设备在证书失效或网络重建前仍可作为其自身身份访问网络；控制器本身仍属于完全信任根。
