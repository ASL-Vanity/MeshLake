# MeshLake 在线授权与成员吊销

## 目标

成员从控制器中删除后，旧成员证书、旧网络 PSK 和已经建立的会话都必须在有限时间内失效。吊销状态本身必须由控制器签名，客户端、根节点和中继不能信任普通 HTTP 来源或成员自报状态。

## 当前已完成

- 新成员证书包含随机唯一 `certificate_id`。
- 证书包含 `network_key_epoch`，并且这些字段属于 Ed25519 签名内容。
- 控制器为每个网络维护授权版本、网络密钥版本、活动成员证书 ID 和已吊销证书 ID。
- `GET /v1/networks/{network_id}/authorization` 返回有效期有限的控制器签名授权清单。
- `POST /v1/membership/refresh` 只接受对应设备 Ed25519 私钥签名的刷新请求，并在 5 分钟内拒绝 nonce 重放。
- 刷新响应包含当前证书、当前网络 PSK 和签名授权清单。
- 删除成员会记录其证书 ID、提高授权版本、生成新网络 PSK 并提高密钥版本。
- 新设备入网时，`meshlaked` 会验证签名授权清单确实授权本机证书，然后才保存网络配置。
- 旧控制器状态会自动补齐成员证书 ID、授权版本和网络密钥版本。
- `meshlaked` 每约 20 秒拉取一次签名授权清单；控制器不可达时不会接受未经验证的新状态。
- 授权清单默认只在 90 秒内有效。清单过期后，本机网络数据面、Root 注册和 Relay 注册都会 fail closed，不再继续使用旧授权。
- 网络密钥 epoch 变化或成员证书接近过期时，代理发送设备 Ed25519 私钥签名的刷新请求，并原子替换成员证书、网络 PSK 和授权清单。
- 控制器返回的授权 epoch 不得低于本机已保存 epoch，避免尚未过期的旧清单回滚本机状态。
- 本机不再出现在签名授权清单中时，代理删除该网络记录、网络 PSK、虚拟地址和路由，并触发传输热重载；旧成员目录和成对会话随传输线程一同清除。
- 收到的对端证书必须同时通过控制器签名验证并出现在本网络当前授权清单中，否则不能进入成员目录、打洞流程或成对会话。
- Root 与 Relay 的签名注册必须携带覆盖每张成员证书的当前授权清单，并拒绝无清单、过期、已吊销或旧网络密钥 epoch 的注册。
- 刷新响应里的普通 `revoked` 字段不能单独触发删除；代理只根据已验证的控制器签名授权清单执行吊销。

## 吊销时序与边界

- 正常运行且能访问控制器的成员通常在下一次约 20 秒刷新内看到删除和密钥轮换。
- 已取得旧证书、旧 PSK 和设备私钥且拒绝执行刷新逻辑的失陷客户端，可以在旧签名授权清单尚未过期时尝试重新注册；严格 Root/Relay 会在该清单 90 秒到期后拒绝它。
- 已取得更新清单的正常成员会立即拒绝不在活动成员列表中的旧证书，因此旧成员不能重新进入这些成员的目录或会话。
- 控制器不可达不会延长授权租约。最后一份清单过期后数据面停止，恢复访问并取得有效清单后才可继续。

## 尚未完成
