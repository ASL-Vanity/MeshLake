# MeshLake v0.1.0

发布日期：2026-09-13。

首次公开发布 Windows 图形管理端、Windows/Linux 无界面客户端和自托管服务。完整使用说明与重写后的 README 随源码和两个程序包一同提供。

## 下载内容

- `MeshLake-Windows-x64.zip`：GUI、CLI、Agent、Controller、Root、Relay、Wintun、离线说明与许可证。
- `MeshLake-Linux-x64.tar.gz`：CLI、Agent、Controller、Root、Relay、离线说明与许可证；x86_64，glibc 2.17+。
- `SHA256SUMS.txt`：两个压缩包的 SHA-256。包内另有逐文件校验清单和记录版本、平台与源码提交的 `RELEASE.json`。

Windows 需要 VC++ x64/UCRT 运行库；GUI 需要正常图形驱动，创建虚拟网卡需要管理员权限。Linux 客户端需要 TUN、`iproute2` 和 root 或等效网络管理权限。

## 本版功能

- Windows GUI 提供概览、连接与网卡、加入网络、控制器管理、出口与网关、维护工具六页，当前 CLI 功能均有相应图形入口。
- 邀请和手动入网、Controller 网络/成员/令牌管理、路由/DNS/出口策略、诊断和脱敏 JSON 导出。
- Agent/Controller 加密备份恢复、旧 Agent 状态修复、自启动以及四类独立服务参数与运行管理。
- 内置 MiSans Regular/Medium、A「双岸」标志与统一矢量图标；五种主题色、中英文、浅色/深色/系统主题。
- 缩放改为六档固定选项，修复拖动滑块时界面随缩放发生抖动的问题；移除 F5 与 Ctrl+, 快捷键及提示。
- Windows/Linux 无界面组件保持独立；退出 GUI 不会停止后台服务。
- 合入 CLI 功能补齐、Agent 旧状态修复和 Windows 适配器相关修正，并发布此前开发的出口、TLS Relay 与 TURN 功能。

## 已有验证与边界

本版复用同一批已经构建、核对源码输入并完成相应检查的程序。发布阶段另行核对压缩包内容、程序哈希、文档、许可证与 Linux 文件权限。

- 最新 GUI 常规测试：66 通过、0 失败、5 项需显式环境的测试未在该轮执行。
- 另有原生隔离备份往返、四类服务共 47 个实际帮助选项及私有 CA HTTPS 检查通过的记录。
- CLI 在两台 Windows 和一台 Linux 隔离环境中各完成 58 项检查，共 174 项，覆盖管理、状态维护及错误路径。
- 已有一次 Windows 到 Linux 的 Relay TCP/UDP 数据面通过记录。

上述结果不等于全部场景验收通过。真实跨主机直连、双栈、路由/DNS 生效、出口防泄漏、完整故障切换、所有 GUI 交互和干净 Windows 安装仍有未覆盖项目。macOS、移动客户端与 Linux GUI 尚未提供。

## 开始使用与升级

先阅读 [完整使用说明](../user-guide.md)。新安装需要显式启动 Agent；首次初始化 Controller 需要领取管理员令牌，再创建网络并签发邀请。

从先前开发版升级时，先正常停止对应服务，再导出加密状态备份，然后将完整程序目录一起更新。不要只替换 `MeshLake.exe`，也不要直接把 Windows 的 DPAPI 状态文件复制到另一台机器。状态恢复、自启动路径与故障处理见使用说明。
